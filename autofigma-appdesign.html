AutoFigma-AppDesign

Describe an app. It studies three real Behance case studies, writes a design spec where every number has a source, and draws every screen in Figma.

1. Project Context

Ask an AI to “design a fitness app” with no other input and you get the average of its training data: cards inside cards, a border and a shadow on every block, purple-blue gradients and filler copy. figma-app-design-builder works the other way round. It learns from real work first, lets the person decide every style question, and only then designs, strictly by the agreed rules.

Role Creator: concept, skill design and the example run
Stack Claude Code Skills, Figma MCP, Python 3, Pillow
License MIT, open source

2. How It Works

  • 0 · Brief: Asks who the app is for, the must-have features and the feel, then drafts a site map and confirms it.
  • 1 · Pick 3 on Behance: Takes the top results from Most Appreciated, Most Viewed and Most Discussed, scores them on popularity and picks three whose styles clearly differ.
  • 2 · Extract: Uses the author’s style-guide values when there is one; everything else is measured on a grid where one cell is one design pixel.
  • 3 · DESIGN.md: Compares the three works side by side, one row per dimension, with every value sourced.
  • 4 · Your choices: 2–3 rounds of multiple-choice questions; each option states exact values and where they come from.
  • 5 · Figma screens: Builds variables, text styles and components, then draws each screen and checks it against Apple HIG and Nielsen’s 10 heuristics.
  • 6 · Walkthrough audit: Walks each main task end to end and reports problems a single screen cannot show.

3. Key Features

  • Every claim has a source: every value and judgement carries a tag: a Behance work, a measurement, the author’s style guide, Apple HIG, Nielsen, the user’s own choice, or an honest “AI suggestion”.
  • Three helper scripts: rank_candidates.py scores the candidate pool, grid_extract.py measures screens at one cell per pixel, and contrast.py checks WCAG contrast against the HIG thresholds.
  • Anti-AI-look checklist: symptoms in visuals, structure, copy and data, with what well-regarded designs do instead. It constrains the design and doubles as the review checklist.

4. Install and Use

Install it as a Claude Code plugin, restart Claude Code, then just describe the app you want. It needs Claude Code, the Figma MCP server and a browser tool for reading Behance.

Claude Code
/plugin marketplace add ws0325/AutoFigma-AppDesign
/plugin install figma-app-design-builder@autofigma-appdesign

5. Example: Repwise

The repository includes a complete run for Repwise, a demo strength-training log: 3 Behance references chosen from 32 candidates, a sourced DESIGN.md, 18 high-fidelity Figma screens with Dark copies, and a walkthrough audit that fixed eight problems.
